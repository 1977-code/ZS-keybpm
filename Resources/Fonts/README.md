# Шрифты

Компилируются в бинарник через `juce_add_binary_data` (`CMakeLists.txt`), поэтому
лежат в репозитории: плагин не зависит от того, что установлено в системе.

| Файл | Семейство | Правообладатель | Источник |
|---|---|---|---|
| `MontserratBold.ttf`, `MontserratMedium.ttf` | Montserrat | The Montserrat Project Authors | [github.com/JulietaUla/Montserrat](https://github.com/JulietaUla/Montserrat) |
| `InterMedium.ttf` | Inter | The Inter Project Authors | [github.com/rsms/inter](https://github.com/rsms/inter) |

Оба семейства — SIL Open Font License 1.1, полный текст в [`OFL.txt`](OFL.txt).
Лицензия разрешает встраивание в программу и распространение вместе с ней; условие
— сохранять текст лицензии и копирайты, что и делает этот каталог.

Те же начертания использует сайт студии, поэтому плагин и
[zsr.artspace1977.ru](https://zsr.artspace1977.ru) читаются как один бренд.
